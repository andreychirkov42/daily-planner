# Clepsy — планировщик задач для Windows

Личный планировщик: Go-сервер со встроенным веб-интерфейсом, иконка в трее Windows, мини-панель над треем и окно программы на WebView2. Данные лежат в `data.json` рядом с exe. Интерфейс на русском, общение с пользователем тоже на русском.

Репозиторий: https://github.com/andreychirkov42/daily-planner (публичный). Модуль Go называется `dailyplanner`, внутренние имена (папка проекта, папка WebView2 `%LOCALAPPDATA%\DailyPlanner`) остались от старого названия «Ежедневник» — не переименовывать, это сломает данные и автозапуск.

## Сборка и проверки

```powershell
.\build.ps1        # или двойной клик по build.bat
```

Скрипт по порядку: `gofmt -l`, `node --check` для всех JS, `go vet`, `go test -count=1 ./...` (включая проверку страниц в браузере без окна) и только потом `go build -trimpath -ldflags "-H windowsgui"` → `Clepsy.exe`. Запущенный Clepsy останавливает и запускает заново (`-autostart`). **Собирать exe только через build.ps1** — если тесты упали, exe не меняется.

- Не возвращать `-s -w` в ldflags: «обрезанные» Go-бинарники чаще ловят ложные срабатывания антивируса.
- `build.ps1` должен оставаться в UTF-8 **с BOM**, иначе Windows PowerShell 5.1 ломает кириллицу. Go-файлы — UTF-8 **без BOM** (иначе gofmt падает). `Set-Content -Encoding UTF8` в PS 5.1 добавляет BOM — для .go использовать `[IO.File]::WriteAllText` с `UTF8Encoding($false)`.
- Иконка: `go run ./tools/genicon -preview=<png>` рисует лист вариантов, `go run ./tools/genicon -variant=<имя>` пишет `assets/icon.ico`, `assets/icon.png`, `web/icon.png` (по умолчанию `line-deep` — белые часы одной линией на тёмно-фиолетовом). После смены иконки или версии обновить ресурсы exe:
  `go run github.com/tc-hib/go-winres@v0.3.3 simply --arch amd64 --icon assets/icon.ico --manifest gui --product-name "Clepsy" --file-description "Clepsy — задачи и планы" --product-version X.Y.Z --file-version X.Y.Z --original-filename "Clepsy.exe"` (создаёт `rsrc_windows_amd64.syso`, он в git).
- Версия программы: константа `appVersion` в `main.go` + версия в ресурсах exe (команда выше).

**Android** (ветка `mobile`): `.\build-android.ps1 [-Install]` — те же проверки, Go-сервер как `libclepsy.so` (arm64 и x86_64 для эмулятора) и `Clepsy.apk` из `android/` (Java + WebView). Устройство, ловушки и план — `docs/ANDROID.md`. При заданном `CLEPSY_TOKEN` API требует cookie `clepsy` — не убирать, иначе данные доступны любому приложению на телефоне.

Флаги exe: `-addr` (по умолчанию `127.0.0.1:8080`), `-sync-addr` (приём синхронизации, `:8092`, слушает только если включено в настройках), `-data`, `-no-open`, `-no-tray` (только сервер), `-autostart` (тихий запуск), `-popup` (сразу показать мини-панель).

## Устройство

**Go (корень):**
- `main.go` — флаги, единственный экземпляр (порт занят → просит запущенную копию показать окно через `POST /api/app/open`), HTTP API, `guard` (только Host localhost/127.0.0.1, проверка Origin и `Content-Type: application/json` для изменяющих запросов — защита от сайтов в браузере и DNS rebinding), настройки программы.
- `store.go` — данные (`Data`: tasks, lists, habits, notes, pomos, series, pomoSettings, sketches, app), атомарная запись `data.json` (tmp + rename), повторы задач, перенос невыполненного (`Rollover`: `carry` = `move` переносит на сегодня, `shift` пересобирает план `Series` по недельной сетке `PerDay[вс..сб]`).
- `pomo.go` — общий таймер Помодоро на сервере (окно, мини-панель и трей показывают одно состояние), авто-перерыв, настройки длительностей.
- `sync.go` — синхронизация телефона с ПК: слияние `mergeData` (последняя правка по `updatedAt`, надгробия `deleted`), сервер приёма на ПК (`:8092`, код из настроек), клиент `runSync` на телефоне. Подробности — `docs/ANDROID.md`. Любая новая правка данных в `store.go` должна ставить `UpdatedAt` (или надгробие), иначе не дойдёт до другого устройства.
- `sketch.go` — холст: метаданные в `data.json`, PNG-файлы в `sketches/` рядом с данными.
- `tray_windows.go` — трей (fyne.io/systray), мини-панель и окно программы (github.com/jchv/go-webview2), автозапуск, тёмный заголовок окна через DWM. `tray_other.go` — заглушка для других ОС.
- Тесты: `main_test.go` (логика), `smoke_test.go` (Edge/Chrome без окна открывает `/?smoke=1` и `/popup.html?smoke=1`; страницы сами обходят все разделы и выставляют `data-ready`; любая ошибка JS попадает в `data-errors` и валит тест).

**Фронтенд (`web/`, встраивается в exe через `go:embed` — после правок нужна пересборка):**
- `index.html` + `style.css` — основная страница; модули `js/*.js` — обычные скрипты без сборщика, общая глобальная область, порядок подключения важен: `core, quickadd, render, views, plan, detail, actions, pomodoro, ui, sketch, settings, sync, mobile, main`.
- `js/mobile.js` — вёрстка для телефона (класс `m` на `<html>` при ширине ≤ 760 px или `?mobile`): нижняя панель, разделы `plan`/`timer`/`more`, меню «⋮» и шторка добавления, `window.clepsyBack` для кнопки «Назад» в Android. Доска, расписание, матрица и холст на телефоне не показываются (`DESKTOP_ONLY`). Блок Помодоро один — раздел «Таймер» переносит его из боковой панели и `renderView` возвращает обратно. Смоук-тест проходит и `/?smoke=1&mobile=1`.
- `shared.js` — общее для окна и мини-панели (даты, быстрый ввод, клиент Помодоро, форма настроек таймера); `icons.js` — набор линейных иконок (`icon(name)` в шаблонах, `<i data-i="name">` + `hydrateIcons()` в статичной разметке). Эмодзи в интерфейсе не использовать — только иконки из `icons.js`.
- `popup.html` — мини-панель над треем (самостоятельная страница со своими стилями).

## Ловушки, на которые уже наступали

- **`$$` в строке замены.** В JS `str.replace(a, b)` превращает `$$` в `b` в один `$` — так сломался `$$(...)` (селектор всех элементов). При правках скриптами использовать `split(a).join(b)`.
- **Не называть параметры `icon`** (и другими именами глобальных функций) — перекрывает `icon()` из `icons.js`.
- **WebView2 и потоки.** Колбэки `wv.Bind` выполняются не в главном потоке; создавать/показывать окна только через `popup.wv.Dispatch(...)`. Очередь `Dispatch` разбирает только цикл `Run` мини-панели — у окна программы своего цикла нет, его `Dispatch`/`Eval` из других потоков не вызывать.
- **Крестик окна.** `WM_CLOSE` перехвачен (`mainWndProc`): по настройке прячет в трей или завершает программу — иначе `DestroyWindow` → `PostQuitMessage` закрыл бы всё приложение. Двойной клик по значку заголовка разворачивает окно, а не закрывает.
- **Автозапуск** — только запись `HKCU\...\Run\Clepsy` + флаг «включено» в `Explorer\StartupApproved\Run` (без флага Windows 11 пропускал запись). **Не создавать ярлыки и не запускать скрытый PowerShell**: Защитник Windows принял это за `Trojan:Win32/Bearfoos.A!ml` и удалил exe (версия 1.1.1). Планировщик заданий без прав администратора недоступен.
- **Мини-панель** позиционируется над настоящей панелью задач (`SHAppBarMessage`): при автоскрытии рабочая область доходит до края экрана.
- **Анимации.** Карточкам задач анимация появления — только новым (`S.enter`), иначе список «моргает» при каждой перерисовке; `load()` не должен помечать все задачи заново.
- **Градиентный текст** (`background-clip: text`) — нужен `::selection` с видимым цветом, иначе выделение выглядит пустой плашкой.
- Темы окна и браузера хранятся отдельно (разный localStorage); заголовок окна красит только само окно (`window.chrome.webview`).
- Для проверок без вмешательства в запущенную копию: тестовый экземпляр `Clepsy.exe -no-open -data <копия data.json> -addr 127.0.0.1:8091` с `DAILYPLANNER_WEBVIEW_DIR=<временная папка>`; DevTools WebView2 — `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=NNNN`.
- Скриншоты для README снимать через Edge без окна (`--headless=new --screenshot --window-size --force-device-scale-factor=2`, тёмная тема `--force-dark-mode`, светлая `--blink-settings=preferredColorScheme=1`) на отдельной демо-копии данных, мини-панель — внутри страницы-рамки (минимальная ширина окна Edge без окна около 500 px).

## Правила работы

- **Пушить на GitHub и выпускать релизы — только когда пользователь попросит** (или для действительно важного исправления, спросив). Локальные коммиты — нормально. Подпись коммита: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Визуальные изменения** (иконки, дизайн) — сначала показать пример (картинку или страницу-пример), применять только после выбора пользователя.
- Не трогать антивирус, исключения Защитника и прочие настройки безопасности Windows — это решает пользователь.
- Перед сборкой релиза: `.\build.ps1`, затем `gh release create vX.Y.Z "<exe>#Clepsy.exe (Windows x64)" SHA256SUMS.txt --title "Clepsy vX.Y.Z" --notes-file <файл> --latest --target main` (имя файла в релизе — латиницей).
