# ⏳ Clepsy

Личный планировщик задач для Windows и Android: задачи, привычки, таймер фокус-сессий. Работает без облака — данные хранятся у тебя, телефон синхронизируется с компьютером напрямую.

## Скачать

**[Последняя версия](../../releases/latest)**: `Clepsy.exe` для Windows 10/11 (установка не нужна) и `Clepsy.apk` для Android 8+. Дальше Clepsy обновляется сам.

## Что умеет

- Задачи со сроками, приоритетами, списками, тегами, подзадачами и повторами; быстрый ввод вида `Сдать отчёт завтра в 18:00 !3 #работа`.
- Разделы «Сегодня», «Предстоящие», календарь, канбан-доска, расписание дня, матрица приоритетов, статистика.
- Привычки, заметка дня, холст для набросков, таймер фокус-сессий.
- Мини-панель в трее Windows и приложение для телефона со своей вёрсткой.
- Синхронизация телефона с компьютером по Wi-Fi или Tailscale и автообновление с GitHub.

## Сборка

`.\build.ps1` — Windows (`Clepsy.exe`), `.\build-android.ps1` — Android (`Clepsy.apk`). Оба сначала прогоняют все проверки и тесты. Подробности — в [CLAUDE.md](CLAUDE.md) и [docs/ANDROID.md](docs/ANDROID.md).

Часть иконок нарисована по мотивам [Lucide](https://lucide.dev) (ISC).
